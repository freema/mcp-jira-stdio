# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
[Report a vulnerability](https://github.com/freema/mcp-jira-stdio/security/advisories/new)
(Security tab → Advisories → Report a vulnerability). Do not open a public issue.

Include the affected version, what an attacker can do, and how to reproduce it. You will get a
reply within 14 days. Fixes are released as a patch version, and the issue is published as a
GitHub security advisory once the fix is out, crediting the reporter unless they prefer otherwise.

## Supported versions

Only the latest release gets security fixes. Upgrade with `npm install mcp-jira-stdio@latest`.

## Published advisories

See [Security advisories](https://github.com/freema/mcp-jira-stdio/security/advisories).
